新增 Android 控制面 APP（Flet）+ 自签名打包

GUI（gui/）：
- Flet 跨平台，桌面原生窗口 + Android APK
- 自适应布局：宽屏左列表右编辑，窄屏单栏切换
- 全局默认人格 + 每会话独立覆盖
- 网络请求走后台线程，不阻塞 UI
- token 存本地，不硬编码
- 已移除 Web 模式（控制面是本机工具，不需要浏览器入口）

签名（自签名，用于发布）：
- make_keystore.ps1 生成 RSA 4096 密钥，有效期 10000 天
- 密码随机生成 32 位，存 keys/keystore.properties
- keys/ 整个目录 gitignore，防止密钥泄露
- 打包脚本从 properties 读签名信息，通过
  --android-signing-* 传给 flet build

签名验证结果：
  DN: CN=Sonder-Traveller, OU=super-feiyu, O=Sonder, C=CN
  （之前是 CN=Android Debug，说明签名参数确实生效了）

.gitignore 新增：keys/、*.keystore、*.jks、keystore.properties、
gui/build/、gui/.venv/、*.apk

打包踩的坑记在 docs/GUI_ANDROID.md：
- Flet 下载 Python 构建清单时 Python SSL 报 UNEXPECTED_EOF，
  改用 PowerShell 预下载 + FLET_PYTHON_BUILD_MANIFEST
- 入口文件必须叫 main.py
- Android 许可需先接受
- JAVA_HOME 与 PATH 里 java 版本不一致
- Flet 1.x API 变化（ft.padding → ft.Padding 等）
