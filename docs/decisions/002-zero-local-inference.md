# ADR-002：本机零推理，全部远程 API

**状态**：已定

---

## 决策

本机只做协议转发与数据落盘，**不加载任何模型权重**。

## 问题

"全家桶"通常意味着本地跑：embedding 模型、TTS 模型、视觉模型。
在 1G 机器上算一下：

| 组件 | 内存/磁盘 |
|---|---|
| Ollama + bge-m3 | 1.2 GB |
| Breeze-TTS-2 | 3.32 GB 模型 |
| GPT-SoVITS | 数 GB + 需 GPU |

**任何一项都超过整台机器的内存。**

## 收益

| 项 | 说明 |
|---|---|
| 内存 | 只留 AstrBot 级（约 50 MB）+ 数据 |
| 冷启动 | < 2 s，无模型加载 |
| 迁移 | 拷 `data/` 即走，无环境依赖 |
| 二进制 | 无 CUDA/ONNX 依赖，静态链接 < 10 MB |

## 代价

| 代价 | 说明 |
|---|---|
| 依赖网络 | 断网即不可用 |
| 依赖第三方服务 | 免费额度可能变 |
| 隐私 | 消息经第三方 API（对个人陪伴场景可接受） |
| 延迟 | 比本地推理高（网络往返） |

## 关于语音

本地 TTS 音色更好（可克隆），但模型动辄数 GB。
本项目选 **Edge-TTS**：零内存、无需 key、中文女声质量够用。

**接受**：音色不是"鱼的专属声音"，这是 1G 下的必然妥协。
