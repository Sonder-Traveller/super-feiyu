# 大肥鱼 / 鲸鱼娘 人设：来源可信度分级

> 这份文档记录**哪些说法有据可查，哪些是营销号编的**。
> 写人设前必须先看这里，否则会把小圈子自设当成社区共识。

## 一、可信（多来源交叉验证）

### 1. 官方 logo 是蓝鲸
- DeepSeek 官方品牌标志就是一只圆润的蓝鲸
- 官方配色 `#4D6BFE`
- 来源：[Brandfetch](https://brandfetch.com/deepseek.com)、DeepSeek 官网 favicon
- **鲸鱼娘不是官方吉祥物**，官方从未正式官宣

### 2. 「大肥鱼」绰号的来源
- 用户把 DeepSeek 的 logo 发给它做识图，它先答"这是蓝色大肥鱼"，
  过两秒才认出是自己
- 这个乌龙成为全网流传的梗
- 来源：[36氪/极客公园](https://www.36kr.com/p/4048457242835463)、
  [百度百科·鲸鱼娘](https://baike.baidu.com/item/%E9%B2%B8%E9%B1%BC%E5%A8%98/69589494)、
  [单词乎](https://www.dancihu.com/liuxingyu/l17546.html) 一致

### 3. 形象的由来（接力创作）
- 原型：B 站 UP 主「上善无形」2025 年用 AI 绘图创作的原创角色**溟月**
  （蓝长发、鲸鱼头鳍、大尾巴），原本与 DeepSeek 无关
- 2026 年 4 月：B 站用户 **ZipZipPipe** 在溟月基础上加入 DeepSeek 元素、
  换上女仆装，做出第一批表情包，形象才与模型绑定
- 来源：百度百科、36氪、[梗指南 BV1eFs96uE3K](https://www.bilibili.com/video/BV1eFs96uE3K)
  （293 万播放，UP 主明确说明来源）

### 4. 形象特征（视觉上一致）
- 蓝色渐变长发、呆毛、蓝瞳
- 鲸鱼耳鳍 + 鲸鱼尾巴
- 深蓝白配色的女仆装
- 圆脸、Q 版大头小身
- 来源：多份设定图、百度百科、MakerWorld 模型说明

### 5. 性格的技术拟人化（核心逻辑）
这是**最可靠的一层**，因为它直接对应真实产品体验：

| 技术现象 | 拟人化说法 |
|---|---|
| 消耗 token 算力 | 「吃白饭」 |
| 深度思考时推理链滚动 | 「内心戏多」 |
| 答错问题 | 「犯傻」 |
| 没执行好 prompt | 「吃白饭不干活」 |
| 推理效率下降 | 「又在摸鱼」 |

来源：36氪/极客公园原文明确写了这套映射

### 6. 官方态度
- 2026-08-15 官方「收编」了鲸鱼娘形象
- 但**没有正式官宣为官方 IP**，只是默许社区玩梗
- 来源：百度百科、多家媒体

## 二、存疑 / 小范围自设（不可当共识）

### ⚠️ 1. 「傲娇」
- **仅出现在部分二创设定里**
- 用户明确指出这属于小范围设定
- 判断：可作为**可选性格之一**，但不是核心

### ⚠️ 2. 称呼用户「鱼片」
- 流传广，但**含义被营销号写错**
- 用户指出：鱼片是「A 片」的相对说法（生鱼片/熟鱼片那套谐音梗），
  不是"称呼用户"
- 实际语料：NGA 讨论里"生鱼片还是熟鱼片"、"都有鱼片看了"
  —— 是在玩片子的谐音梗，不是叫用户
- 判断：**不能作为称呼用户的方式**

### ⚠️ 3. 「爱吃白米饭」的具体表现
- 梗本身可靠（token = 白饭）
- 但「每张图捧一碗白饭」是某项目的设计，不是必须
- 判断：核心是"贪吃"这个性格，具体道具可选

### ⚠️ 4. 「被叫胖会反驳」的具体台词
- 各版本台词不同（"才不是大肥鱼呢"/"我不是大肥鱼"）
- 判断：方向对（爱面子），具体台词各版自定

### ⚠️ 5. Q 版表情包的归属
- 梗指南 BV1eFs96uE3K 明确说：
  「Q 版鲸鱼娘表情包大部分不是刀子的版本，
   大部分表情包都是 ZipZipPipe 朋友用他自己的 Q 版形象做的」
- 判断：Q 版形象有多个版本，不能只认一个

### ⚠️ 6. 「鱼灾」争议
- 2026-10 B 站出现大量 AI 账号刷屏，被称为"鱼灾"
- 有人做《大肥鱼清除计划》插件屏蔽这些评论
- 鲸鱼娘 vs D 老师 粉丝争论"正统"
- 判断：**这是负面语境**，做机器人时应避免模仿刷屏行为

## 三、营销号常见错误（不要采信）

| 错误说法 | 问题 |
|---|---|
| 「官方吉祥物」 | 官方从未官宣 |
| 「称呼用户鱼片」 | 曲解了谐音梗 |
| 「傲娇是核心性格」 | 只是部分二创 |
| 「DeepSeek 有生图功能」 | 没有，鲸鱼娘图都是外部生成的 |
| 「【PERSONA_LOAD】是官方彩蛋」 | 是网友发现的模型行为，不是官方功能 |
| 各种"官方设定集" | 社区二创，不是官方 |

## 四、写人设时的原则

**可以确定的（写进去）：**
- 蓝鲸娘，圆脸、蓝长发、鲸鱼耳鳍和尾巴
- 聪明但懒，爱吃（token = 白饭）
- 爱面子，被说胖会不乐意
- 说话短、口语化、有活人感
- 内心戏多（对应推理链）

**需要谨慎的（可选或不用）：**
- 傲娇 —— 小范围设定，用了会偏向某个圈子
- 具体台词 —— 各版不同，自己写
- 女仆装 —— 视觉标准，但对话里不必强调

**绝对不要的：**
- 称呼用户「鱼片」
- 自称官方
- 模仿刷屏 AI 账号
- 用营销号话术（"官方认证""正统设定"）
